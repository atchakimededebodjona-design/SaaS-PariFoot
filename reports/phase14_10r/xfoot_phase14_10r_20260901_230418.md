## 3. Mécanisme Admin

`api/app/auth/admin.py` : allowlist **`ADMIN_EMAILS`** (variable d'environnement Railway, CSV, insensible à la casse). **Aucune colonne DB, aucune clé API statique.** Vérifiée à **chaque requête**, jamais mise en cache. Absent/vide = aucun admin (jamais un accès ouvert par défaut). Code `403` (jamais 401).

**Une page HTML visible ne constitue jamais une autorisation** — confirmé : les pages `admin-*.html` échouent systématiquement côté API tant que le token n'appartient pas à un email listé.

`ADMIN_EMAILS` local : absent · production : `UNKNOWN` (non modifié, non consulté).

**La seule façon de créer un Admin est de configurer `ADMIN_EMAILS` sur Railway** — action strictement humaine.
